# 航空零件检修 —— 信号检测论实验

一个基于网页的**信号检测论（Signal Detection Theory, SDT）**交互式心理学实验，模拟航空零件检修场景，让被试在干扰项中辨别真正的裂痕。

## 实验简介

你扮演一名航空公司的**航线检修员**，需要在零件表面寻找真正的裂痕（信号）。

- **信号（裂痕）**：边缘锐利、颜色更深
- **噪音（干扰项）**：油污（圆润、模糊）或老化（整体暗淡），看起来也很深很乱，但并没有损坏
- **限时**：每试次 3 秒

## 功能特性

- 🎯 完整的信号检测论实验流程（20 试次 / 轮）
- 🖼️ 动态生成零件 SVG，随机位置、随机旋转、随机大小
- 🔍 四种难度可调（简单 / 中等 / 困难 / 极难），对应不同的辨别力 d'
- ⏱️ 实时倒计时，超时自动判为"放行"
- 📊 自动计算并展示：
  - 击中(H)、漏报(M)、虚报(FA)、正确拒绝(CR)
  - 命中率 P(Hit)、虚报率 P(FA)
  - 辨别力 d'、判断标准 c
  - 总准确率
- 📝 历史轮次记录，支持多轮累计统计
- 🔄 可完全重置实验

## 使用方法

1. 下载或克隆本仓库
2. 直接用浏览器打开 `planerepair-6.html`
3. 阅读任务简报后点击"开始检修"
4. 在 3 秒内判断是否存在裂痕：
   - 点击 **🔧 发现裂痕，送修**（报告有信号）
   - 点击 **✅ 零件完好，放行**（报告无信号）
5. 每轮 20 试次结束后，可调节下一轮难度并查看累计数据报告

无需安装任何依赖，纯前端实现。

## 技术实现

- 纯 HTML / CSS / JavaScript，无第三方依赖
- 使用 SVG 动态绘制零件图形
- 通过 `radialGradient`、`linearGradient`、`feGaussianBlur`、`clipPath` 等实现信号与噪音的视觉差异控制
- 使用正态分布逆累积函数（近似算法）计算 z 分数，进而得出 d' 和 c

## 核心公式

- 辨别力：**d' = z(Hit) − z(FA)**
- 判断标准：**c = −0.5 × [z(Hit) + z(FA)]**
